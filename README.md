## 💻 Overview

Polaris runs entirely in the terminal behind a **paginated dashboard** - every module is one or two keystrokes away. It ships with **13 switchable themes**, a plugin-style module loader, and a self-bootstrapping dependency system.

No GUI clutter. No browser tabs. No background services.

**60+ modules. 8 categories. One command to launch.**

---

## 🤖 Discord Automation

For people who live inside Discord's API.

**Webhook Manager** - Bulk-send, rotate, and clean up webhooks.  
**Account Tools** - Token inspection, session management, presence scheduling.  
**Username Checker** - Multi-threaded handle availability sweeps.  
**Server Auditor** - Structure export, permission mapping, layout cloning.  
**Nitro Generator** - High-speed code generation and validation.  
**Selfbot Utilities** - Presence automation, status cycling, DM tooling.  
**Bot Framework** - Configurable runner driven by `core/botcfg.json`.  
**Nuke Bot** - Dedicated console bot with `.kill`, `.massban`, `.erase`.

## 🔎 OSINT & Research

Passive recon, public-record aggregation, and metadata forensics.

**Network Recon** - Port scanner, WHOIS lookup, recursive DNS.  
**Subdomain Enumerator** - Passive subdomain discovery across public sources.  
**Person of Interest** - Public-record aggregation into a single profile.  
**Metadata Extraction** - EXIF, audio tags, and document properties.  
**Email Header Analyzer** - SPF, DKIM, DMARC chain analysis.  
**Favicon Hash Lookup** - Identify frameworks and origin infrastructure.  
**Google Dork Builder** - Prebuilt query generator for targeted recon.  
**IP Utilities** - Grabber and continuous latency pinger.

## 👾 Exploitation Suite

Authorized-only modules for lab work and internal assessments.

**Reworked Navi RAT** - Rebuilt from the original Navi Discord RAT. Stability patches, cleaner PyQt5 interface, reduced AV false positives. Full remote access with Discord-based C2.  
**Recovery Tool** - Blue-themed GUI for browser data and token extraction.  
**Crypto Clipper** - Intelligent cryptocurrency address redirection.  
**Keylogger** - Stealthy background input recording.  
**SQL Scanner** - Automated vulnerability detection.  
**Email Bomber** - High-volume mail stress testing.  
**Brute Forcer** - Credential attack automation.  
**Website Cloner** - Instant local cloning of any site.

## 🔐 Security & Utilities

Everyday tools that sit next to the bigger modules.

**Obfuscator V2** - Python obfuscation with XOR layers and anti-print protection.  
**Hash Verifier** - MD5, SHA1, SHA256 generation and integrity checks.  
**Cryptography** - Base64 codec and entropy-based password generator.  
**Password Strength Analyzer** - Real-time entropy scoring and feedback.  
**Proxy Tools** - High-speed scraper and concurrent validity checker.  
**Wallet Scanner** - Cryptocurrency address detection and analysis.  
**QR Generator** - Custom QR creation.
