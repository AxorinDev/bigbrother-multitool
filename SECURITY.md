# Security Policy

## Reporting a Vulnerability

Polaris is a private build. Report issues directly to the maintainer -
do not open a public issue.

- Contact: [@AxorinDev](https://github.com/AxorinDev)
- Response time: best effort, typically within 7 days

Include a clear description, steps to reproduce, and any relevant logs.

## Scope

For authorized security testing only. Do not use against systems,
accounts, or networks you do not own or have explicit permission to test.
